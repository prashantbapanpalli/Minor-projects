# Responsive Product Landing Page
Minor Project 02 - by B Prashant.
**Tech:** HTML5, CSS3 (transitions, media query), Flexbox (navbar/footer), CSS Grid (cards), Tailwind CSS (CDN).
**Features:** responsive navbar with mobile menu, hero banner + CTA, product cards, footer with contact and social links.
**Run:** open `index.html` in a browser (needs internet for the Tailwind CDN).
