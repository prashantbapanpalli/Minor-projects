# To-Do App + Notes App (React)
Minor Project 04 - by B Prashant.

## Overview
One React app with two mini apps (switch with the tabs): a task manager and a note-taking app. Data is saved in the browser (localStorage).

## Features implemented
**To-Do:** add, edit, delete, mark completed, status badge (Completed/Pending), filter (All/Completed/Pending), due dates.
**Notes:** create, edit, delete, grid layout, search, categories, timestamps.
Both are responsive.

## Technologies used
React 19 (functional components, props, useState, useEffect, custom hook), Vite, CSS3, ES6+ (arrow functions, destructuring, spread, map/filter).

## Setup
```
npm install
npm run dev     # http://localhost:5173
```
