# Weather App + Movie Search App
Minor Project 03/05 (API) - by B Prashant.
**Tech:** HTML5, CSS3, JavaScript ES6+ (arrow functions, template literals, destructuring, modules, async/await, fetch), Open-Meteo API, OMDb API.
**Weather:** search by city, shows temperature, condition, humidity, wind speed, handles errors (city not found / network).
**Movies:** search by title, shows poster, rating, release date, genre, handles invalid or empty results.
**Setup:** 1) Get a free OMDb key at omdbapi.com/apikey.aspx and paste it in `config.js`. 2) Serve the folder (ES modules need a server): `npx serve .` or VS Code Live Server. The weather app needs no key.
